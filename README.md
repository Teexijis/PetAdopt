# PetAdopt

Микросервисная система для пристройства животных.

### Микросервисы

1) Account Service - пользователи и авторизация
2) Adoption Service - управление каталогом животных, подача и рассмотрение заявок, подтверждение пристройства
3) Notification Service - обработка событий и создание уведомлений для пользователей и администраторов

Redis используется для кэширования каталога животных. 

Apache Kafka обеспечивает асинхронную передачу событий о заявках и пристройстве животных.
